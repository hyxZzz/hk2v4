# 多智能体集中式训练框架说明

本项目实现了两机协同拦截的集中式训练 + 去中心化执行（CTDE）框架。核心特性如下：

## 环境模型

- **载机与拦截弹**：环境初始化两架载机，共享 12 枚拦截弹。每枚拦截弹记录 `owner`、`current_holder`、`launched_by` 等字段，支持跨机借弹和发射归属统计。
- **状态表示**：训练时提供包含两架飞机、四枚来袭导弹和 12 枚拦截弹的全局观测，特征按照固定顺序拼接。环境还提供 `get_local_obs(plane_id)` 用于去中心化执行。
- **动作逻辑**：动作库扩展为“机动指令 + 目标索引”组合，智能体需显式选择是否发射及指向哪枚来袭导弹。拦截锁定受到 `allow_cross_lock` 与 `max_locks_per_missile` 约束，发射策略优先使用本机弹药，必要时可借用队友弹药并记录借用次数。
- **奖励设计**：团队奖励综合考虑拦截率、生存与安全距离，并加入威胁度惩罚。新增危险距离判别、约束失败惩罚与及时发射奖励，将“何时发射、发射到谁”的决策反馈到回报中。命中事件同时产生归属奖励，用于缓解 credit assignment。

## 强化学习架构

- **网络结构**：`Double_DQN` 采用共享前向骨干 + 双动作头结构，两个 head 分别输出各机动作价值。
- **智能体**：`MyDQNAgent` 维护团队经验，经验回放条目格式为 `(state, (a0, a1), team_reward, next_state, done, attribution)`，训练时对每个 head 分别执行 Double DQN 更新。
- **训练脚本**：`utils/train.py` 更新为双头 DDQN 流程，集中存储团队经验并记录归属指标。验证与预测脚本同步支持多智能体动作接口。

## 使用指引

1. **初始化环境**：`Environment/init_env.py` 与 `reset_env.py` 会生成两架飞机、四枚来袭导弹以及 12 枚拦截弹的初始场景。
2. **训练**：运行 `utils/train.py` 即可开始集中式训练，脚本会定期评估并记录团队表现及借弹统计。
3. **验证与预测**：`utils/validate.py`、`utils/predict.py` 已适配双智能体网络，可用于评估模型与可视化运行。

如需扩展更多飞机或导弹数量，可在初始化参数中调整 `num_planes`、`num_missiles` 和拦截弹分配策略。请确保网络 head 数与环境载机数量一致。
